Remote GeoParquet places, read by DuckDB-WASM straight from object storage

Every row below is fetched, at query time, from Overture Maps' places theme sitting in a 203 MB GeoParquet file on a CDN — no server, no copy in this repo. DuckDB-WASM reads the file over HTTPS range requests; the fixed bbox below (Greater London) is pushed into the SQL so the browser never scans anything outside it. The probe that chose this host over two Foursquare OS Places mirrors, and the exact byte counts, are in README.md.

Pan or zoom the map: viewportFilter: true writes the visible bounds back to the grid's own filters and re-queries DuckDB (GEO-4) — the grid and bytes-fetched KPI narrow with it. Past 20,000 rows in view the map draws density cells, counted by DuckDB (GEO-6); zoom into a small area to see points again. The bar chart stays over the full fixed London bbox (a grouped aggregate, not the map's window). See README.md for a known KPI display finding (F-GEODEMO-G).
